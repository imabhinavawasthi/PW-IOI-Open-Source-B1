# Introduction to JavaScript

## What is JavaScript?

JavaScript (JS) is a **high-level, interpreted programming language** used to make web pages **interactive and dynamic**.

Without JavaScript, websites would only display static content. JavaScript allows websites to respond to user actions, update content without reloading the page, communicate with servers, and create rich user experiences.

### Examples of JavaScript in Action

- Login and signup form validation
- Image sliders and carousels
- Drop-down menus
- Pop-up notifications
- Online games
- Shopping carts
- Weather applications
- Chat applications
- Video streaming websites

---

## History of JavaScript

- **1995:** Created by **Brendan Eich** in just 10 days.
- Originally named **Mocha**.
- Later renamed **LiveScript**.
- Finally renamed **JavaScript**.

Despite the name, **JavaScript and Java are different programming languages.**

---

## Why Learn JavaScript?

JavaScript is one of the most widely used programming languages because it:

- Runs in every modern web browser.
- Powers interactive websites.
- Can be used for both frontend and backend development.
- Has a large community and ecosystem.
- Is required for popular frameworks like React, Angular, and Vue.

---

## Where Can JavaScript Run?

### 1. Browser

JavaScript runs directly in web browsers like:

- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari

Example:

```javascript
console.log("Hello, Browser!");
```

---

### 2. Server (Node.js)

JavaScript can also run outside the browser using **Node.js**, allowing developers to build servers, APIs, and backend applications.

Example:

```javascript
console.log("Hello from Node.js!");
```

---

## What Can JavaScript Do?

JavaScript can:

- Change HTML content.
- Change CSS styles.
- Respond to button clicks.
- Validate forms.
- Perform calculations.
- Fetch data from APIs.
- Store data in the browser.
- Create animations.
- Build full-stack web applications.

---

## JavaScript vs HTML vs CSS

| Technology | Purpose |
|------------|---------|
| HTML | Creates the structure of a webpage |
| CSS | Styles the webpage |
| JavaScript | Adds interactivity and functionality |

Think of a webpage like a human body:

- **HTML** → Skeleton (Structure)
- **CSS** → Clothes & Appearance (Design)
- **JavaScript** → Brain & Muscles (Behaviour)

## Advantages of JavaScript

## Limitations of JavaScript

- Browser security restrictions
- Different browsers may behave slightly differently
- Can be disabled in browsers
- Not suitable for very low-level system programming
