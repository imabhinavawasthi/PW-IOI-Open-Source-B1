# JavaScript Polyfills

A collection of JavaScript Polyfills with simple explanations and implementations. This repository helps you understand how native JavaScript methods work internally by creating your own versions from scratch.

---

## 📌 What are Polyfills?

A **polyfill** is a piece of JavaScript code that provides modern functionality on older browsers that do not support certain JavaScript features.

In simple words, a polyfill acts as a **fallback implementation** of a built-in JavaScript method.
