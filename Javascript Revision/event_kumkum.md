md_content = """# Comprehensive Guide to JavaScript Event Listeners

An **Event Listener** is a core JavaScript mechanism that listens for specific user or browser actions (events) on DOM elements and triggers a callback function when those events occur.

---

## 1. Syntax & Core Parameters

The primary method to register event handlers in modern JavaScript is `addEventListener()`.

```javascript
element.addEventListener(eventType, listenerFunction, options);

```

### Parameter Breakdown

1. **`eventType`** *(string)*: Case-sensitive name of the event (e.g., `'click'`, `'keydown'`, `'DOMContentLoaded'`).
2. **`listenerFunction`** *(function | object)*: The function to execute when the event fires, or an object implementing the `EventListener` interface (`{ handleEvent: function(e) {} }`).
3. **`options`** *(object | boolean, optional)*:
* **`once`** *(boolean)*: If set to `true`, the listener automatically unbinds itself after executing once.
* **`capture`** *(boolean)*: If `true`, forces the listener to execute during the **capture phase** instead of the **bubbling phase**.
* **`passive`** *(boolean)*: If `true`, tells the browser that the function will **never** call `event.preventDefault()`. This optimizes performance for scroll and touch handlers.
* **`signal`** *(AbortSignal)*: Allows removing the event listener via an `AbortController`.



---

## 2. Basic Usage Examples

### Click Event

```javascript
const button = document.querySelector('#submit-btn');

button.addEventListener('click', (event) => {
  console.log('Button clicked!', event);
});

```

### Keyboard Event

```javascript
document.addEventListener('keydown', (event) => {
  if (event.key === 'Escape') {
    console.log('Escape key pressed!');
  }
});

```

### Form Submit Event

```javascript
const form = document.querySelector('#registration-form');

form.addEventListener('submit', (event) => {
  // Prevent page reload on form submit
  event.preventDefault();

  const formData = new FormData(form);
  console.log('Submitted data:', Object.fromEntries(formData));
});

```

---

## 3. The Event Object (`event`)

When an event is fired, JavaScript passes an **Event Object** to the listener callback containing context about what happened.

| Property / Method | Type | Description |
| --- | --- | --- |
| `event.target` | Element | The exact DOM element that originally triggered the event. |
| `event.currentTarget` | Element | The DOM element to which the listener is attached. |
| `event.type` | String | The event type (e.g., `"click"`, `"submit"`). |
| `event.preventDefault()` | Method | Prevents default browser behavior (e.g., submitting forms, following links). |
| `event.stopPropagation()` | Method | Stops the event from propagating further up or down the DOM tree. |
| `event.stopImmediatePropagation()` | Method | Prevents other listeners on the **same element** from executing. |
| `event.isTrusted` | Boolean | `true` if generated by user action; `false` if created via script (`dispatchEvent`). |

---

## 4. Event Propagation: Capturing vs. Bubbling

When an event occurs on a DOM element, it does not happen in isolation. It travels through three distinct phases:

1. **Capturing Phase (Trickling)**: Event travels down from `window` through ancestors to the target element.
2. **Target Phase**: Event reaches the target element (`event.target`).
3. **Bubbling Phase**: Event travels up from the target element back to `window` (default behavior).

```
          WINDOW
            | ^
  Capture   | | Bubbling
  Phase     | | Phase
            v |
         ELEMENT

```

### Code Example: Controlling Propagation

```javascript
const parent = document.querySelector('#parent');
const child = document.querySelector('#child');

// Bubbling Phase (Default)
parent.addEventListener('click', () => {
  console.log('Parent Clicked (Bubbling)');
});

// Capture Phase
parent.addEventListener('click', () => {
  console.log('Parent Clicked (Capturing)');
}, { capture: true });

child.addEventListener('click', (event) => {
  console.log('Child Clicked');
  
  // Stops the event from reaching parent listeners in bubbling phase
  event.stopPropagation(); 
});

```

---

## 5. Event Delegation Pattern

**Event Delegation** is an architectural pattern where a single event listener is attached to a parent element to manage events triggered by any of its present or future child elements.

### Why Use Event Delegation?

* **Memory Efficiency**: Reduces the total number of event listeners in memory.
* **Dynamic Content**: Handles elements added dynamically to the DOM after page load without needing to re-attach listeners.

### Example: Dynamic List Listener

```javascript
// HTML: <ul id="todo-list"><li>Task 1</li><li>Task 2</li></ul>

const todoList = document.querySelector('#todo-list');

todoList.addEventListener('click', (event) => {
  // Target checking using element matching
  const listItem = event.target.closest('li');
  
  if (listItem && todoList.contains(listItem)) {
    console.log('Clicked item content:', listItem.textContent);
    listItem.classList.toggle('completed');
  }
});

```

---

## 6. Removing Event Listeners

To avoid memory leaks, listeners should be cleaned up when no longer needed (e.g., component unmounting in Single Page Applications).

### Method 1: `removeEventListener`

> **Rule**: `removeEventListener` requires a reference to the **exact same function**. Anonymous functions cannot be removed using this method.

```javascript
function handleResize() {
  console.log('Window resized to:', window.innerWidth);
}

// Add
window.addEventListener('resize', handleResize);

// Remove
window.removeEventListener('resize', handleResize);

```

### Method 2: `{ once: true }`

Automatically unbinds after running once:

```javascript
button.addEventListener('click', () => {
  console.log('Runs only once!');
}, { once: true });

```

### Method 3: AbortController Signal

Clean up multiple listeners simultaneously using an `AbortController`:

```javascript
const controller = new AbortController();
const { signal } = controller;

window.addEventListener('scroll', handleScroll, { signal });
window.addEventListener('resize', handleResize, { signal });

// Unbind both listeners at once
controller.abort();

```

|  | `load` | HTML and all assets (images, styles) loaded. |
|  | `resize` | Window dimensions changed. |
|  | `scroll` | Document or container scrolled. |

---

## 8. Performance Optimization & Best Practices

1. **Use Passive Listeners for Touch/Scroll**
* Heavy scroll handlers block the main thread. Marking scroll listeners as `passive: true` informs the browser that scrolling will not be canceled, enabling smoother performance.


```javascript
window.addEventListener('scroll', onScroll, { passive: true });

```


2. **Debouncing & Throttling**
* High-frequency events (like `mousemove`, `scroll`, and `resize`) trigger rapidly. Wrap listeners with debounce or throttle functions to limit execution rates.


3. **Prevent Memory Leaks**
* Always remove listeners on DOM nodes before destroying or replacing them in single-page applications.
